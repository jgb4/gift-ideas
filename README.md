# Gift Ideas

A private gift-shopping list. Paste a product link or describe a gift; AI (via [Puter.js](https://puter.com))
finds the product, writes a short description, estimates the price and finds the best places to buy.

- Password-gated (only a salted PBKDF2 hash of the password is in this repo).
- Lists are stored in your Puter account, not in this repo, and sync across devices.
- No API keys; AI usage comes out of your Puter account's free monthly allowance.
